# Настройка полного цикла CI/CD

Данный репозиторий содержит конфигурацию инфраструктуры (Terraform) и системы управления конфигурациями (Ansible) для развертывания CI/CD среды.

## Структура проекта
- `/terraform` - IaC для развертывания виртуальных машин в Яндекс Облаке.
- `/ansible` - Playbooks для настройки серверов.

## Инфраструктура
Разворачиваются 3 сервера на базе Ubuntu 22.04:
1. `master` - Master-нода Kubernetes.
2. `app` - Worker-нода Kubernetes для приложения.
3. `srv` - Сервер управления (Docker, GitLab Runner, мониторинг).

## Инструкция по развертыванию
